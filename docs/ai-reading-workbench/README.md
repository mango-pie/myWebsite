# AI 精读工作台（Ai-Backend 新功能）

本目录是 **Ai-Backend 本项目** 的新功能开发文档，与 `docs/00`～`06`（原 Knowledge AI 独立项目规划/集成背景）分开存放。

功能定位：从网站/文件发现优质资料 → AI 精炼 Markdown → 人工预览确认 → 发布博客和/或加入知识库问答。

## 推荐阅读顺序

1. 先读 [00-overview.md](./00-overview.md)，对齐整体目标与版本划分。
2. 做第一版：后端读 `02`，前端读 `03`，双方用 `01` 做验收。
3. V1 稳定后读 `04`；前端对接 V2 读 `06`；远期读 `05`。

## 版本一览

```text
V1 MVP
  URL / 文件采集 → AI 精炼 → 预览编辑 → 发博客 / 入知识库
  半自动 Agent：手动候选 URL + 学习大纲展示

V2
  真实搜索 API + 多选批量抓取精炼

V3
  Agent 学习路线：主题 → 大纲落库 → 按章搜文 → 批量精炼
```
